# Security Notes

В проекте реализованы базовые меры защиты данных, конфигурации и API.

## Данные

- Используется обезличенный датасет `data/Customer Churn.csv`.
- В датасете нет ФИО, телефонов, email, адресов, паспортных данных или токенов.
- API и UI не логируют полный входной payload клиента.

## Секреты

- Реальные секреты не нужны для запуска проекта.
- В репозитории хранится только шаблон `configs/.env.example`.
- Локальные `.env` файлы закрыты через корневой `.gitignore`.

## API

- Входные данные валидируются через Pydantic-схему FastAPI.
- `/predict` возвращает нейтральную ошибку без внутренних путей и stack trace.
- `/health` показывает готовность сервиса и факт загрузки модели.

## Зависимости и модель

- Зависимости зафиксированы в `requirements.txt`.
- Модель хранится как локальный артефакт, созданный скриптом `python -m src.models.train`.
- Проект не исполняет пользовательский код и не запускает shell-команды из входных данных.
